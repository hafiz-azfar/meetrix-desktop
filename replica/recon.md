# Meeting workflow research

The Windows installation reported Zoom Workplace 7.1.9 (48550). REA inspected the PE resource inventory for its local launcher without reconstructing source or unpacking assets. Three Computer Use captures document the installed client's home, join dialog, and schedule form. The captures contain account information and stay in the locally ignored `replica/screens` directory.

After checking Zoom's terms, the feature comparison used public product descriptions. Zoom software, accounts, service endpoints, graphics, and UI code are absent from Meetrix. [Zoom terms](https://www.zoom.com/en/trust/terms/) · [Zoom Workplace plans](https://www.zoom.com/en/products/virtual-meetings/)

| Workflow | Gathered evidence | Meetrix route |
|---|---|---|
| Start a meeting | Windows home shows a meeting action and calendar | Home → New meeting → preflight → room |
| Join a meeting | Zoom documents joining by an ID or invitation link with or without an account when the host permits it | Invite or Join a meeting → display name and passcode when needed → preflight → waiting room → call |
| Schedule | Windows form shows start/end time, timezone, recurrence, and invitees | Meetings → Schedule → iCalendar invite |
| Run a meeting | Public Zoom product descriptions cover audio/video, screen sharing and collaboration. Its help center documents selecting media devices before and during a call | Call stage and People, Chat, and Notes panels. Devices opens the microphone, camera, and speaker selectors |
| Manage admission | Public Zoom security material covers passcodes, waiting rooms, and host controls | Preflight and the host's People panel |
| Set meeting defaults | Public Zoom help covers audio checks, camera preview, and join settings | Settings → Audio, Video, or Meeting defaults |
| Use Pro features | Public comparison covers extended duration, cloud storage, AI, and additional workspace tools | Coverage detail in the feature matrix |

The Windows captures establish those three screen states. Account-gated features and meeting-scale behavior are documented through public sources. [Zoom meeting security](https://www.zoom.com/en/trust/security/) · [Zoom Workplace product plans](https://www.zoom.com/en/products/collaboration-tools/)

The guest and device comparisons use [joining without an account](https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0059553) and [desktop audio and video settings](https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0060612).
