# Meetrix 0.1.10 feature comparison

| Area | Meetrix coverage | Remaining scope |
|---|---|---|
| Meetings | Instant meetings, one-time or weekly scheduling, host-approved guests with or without accounts, camera preview, device selection, gallery/speaker mode, and screen/window sharing | Calendar sync and richer recurrence rules, extra display modes, and dial-in |
| Desktop preferences | Light, dark and system themes, chat text size and announcements, reduced motion, and remappable in-app meeting shortcuts | Theme accents, tray behavior, background notifications, and caption styling preferences |
| Media preferences | Microphone meter, test tone and volume, noise reduction, mirrored camera preview, local image backgrounds and blur, screen-share options, and Windows system audio while sharing a display | Video backgrounds, green-screen controls, image filters, microphone replay, audio profiles, native driver and hardware options, and audio-only sharing |
| In-call display and diagnostics | Fullscreen, elapsed-time display, participant filters, local camera pause, presentation layout, and per-track WebRTC samples | Dual-window layouts, richer network diagnostics, configurable push-to-talk, and a diagnostic export |
| Collaboration | In-room chat, raised hands, reactions, polls, whiteboard, shared notes, and breakout rooms managed by hosts and co-hosts | Persistent team chat and attachments. Breakouts still lack pre-assignment, self-selection, countdowns, and voice broadcasts |
| Host controls | Lobby, passcode, lock, admit/decline, individual and bulk mute, ask to unmute, stop camera, remove, end, revocable co-host access, and explicit host transfer in standard meetings | Automatic host succession, transfer in encrypted meetings, waiting room re-entry, organization-wide policy, and independent security evaluation |
| Recording and captions | Local host WebM with participant consent, host-typed captions, per-viewer overlay control, and caption history export | Cloud recording, automatic and translated captions, assigned captioners, and long-form recordings |
| Pro meeting features | 30-hour room cap, 100-participant configuration, and optional end-to-end encryption | Capacity/load verification and AI notes |
| Workplace suite | Desktop and web meeting workspaces | Mail, calendar sync, Canvas, Clips, Tasks, and booking pages |

**Reference coverage.** The comparison covers home, join, scheduling, breakout rooms, manual captions, recording, co-hosts, host transfer, virtual backgrounds, and screen sharing. [Host transfer](https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0067794) · [Screen sharing and sound](https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0060596) · [Managing breakout rooms](https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0062540) · [Manual captions](https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0062000) · [Computer recording](https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0076922) · [Virtual backgrounds](https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0060387) · [Zoom Workplace Pro](https://www.zoom.com/en/products/collaboration-tools/zoom-workplace-pro/)

**Verification scope.** API tests cover admission, breakout grants, room cleanup, and host and co-host authority. Four browser clients use the bundled LiveKit server to exercise host handoff, screen-share sound, breakouts, captions, recording consent, and co-host moderation with synthetic media. The packaged Windows test checks the native display picker and track creation separately. See [the test plan](test-plan.md) for commands and scope.

**Release status.** Scheduling includes a downloadable calendar file and shareable link. Automatic invite email and calendar synchronization remain open. Workplace-wide coverage, production capacity, and operating controls need additional implementation and verification.
