# Meetrix 0.1.16 feature comparison

| Area | Meetrix coverage | Remaining scope |
|---|---|---|
| Meetings | Instant meetings, daily, weekday, weekly and monthly recurrence, custom intervals, up to 52 occurrences, series previews, calendar export, and manual Google Calendar push/pull for linked meetings, host-approved guest access, camera preview, device selection, gallery/speaker mode, and screen/window sharing | Automatic calendar sync and Outlook integration, recurrence beyond one year and rules such as the last weekday of a month, extra display modes, and dial-in |
| Desktop preferences | Light, dark and system themes, chat text size and announcements, reduced motion, remappable in-app meeting shortcuts, and caption size and contrast | Theme accents, tray behavior, and background notifications |
| Media preferences | Microphone meter, test tone and volume, noise reduction, mirrored camera preview, local image backgrounds and blur, screen-share options, and Windows system audio with a display or as an audio-only share | Video backgrounds, green-screen controls, image filters, microphone replay, audio profiles, and native driver and hardware options |
| In-call display and diagnostics | Fullscreen, elapsed-time display, participant filters, local camera pause, presentation layout, sampled WebRTC metrics with codec and jitter when available, local JSON export, and configurable push-to-talk | Dual-window layouts and broader network diagnostics |
| Collaboration | In-room chat, raised hands, reactions, polls, whiteboard, notes, persistent team chat, presentation annotations with shape and text tools and presenter PNG export, and assigned or self-selected breakout rooms with timed returns | Annotation selection and editing, team chat attachments, and breakout pre-assignment and voice broadcasts |
| Host controls | Waiting room re-entry and readmission, passcodes, lock, individual and bulk mute, ask to unmute, stop camera, remove, end, revocable co-host access, and explicit host transfer in standard meetings | Automatic host succession, transfer and waiting room re-entry in encrypted meetings, organization-wide policy, and independent security evaluation |
| Recording and captions | Local WebM, opt-in hosted Egress and private MP4 downloads, manual and offline Windows English captions, per-attendee Hindi and Spanish translation, and caption history export | Live Egress and storage deployment verification, multilingual speech recognition, additional translation pairs, and long-form recordings |
| Pro meeting features | 30-hour room cap, 100-participant configuration, optional end-to-end encryption, and on-device recaps from opted-in caption collection and draft summaries from selected English notes | Capacity/load verification and automatic room-wide transcription |
| Workplace suite | Desktop and web meeting workspaces with private Canvas and Tasks, local Clips, booking pages, and calendar subscriptions | Mail, automatic or Outlook calendar account sync, collaborative Canvas and Tasks, and hosted clip sharing |

**Reference coverage.** The comparison covers home, join, scheduling, breakout rooms, manual captions, recording, co-hosts, host transfer, virtual backgrounds, and screen sharing. [Host transfer](https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0067794) · [Screen sharing and sound](https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0060596) · [Managing breakout rooms](https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0062540) · [Manual captions](https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0062000) · [Computer recording](https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0076922) · [Virtual backgrounds](https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0060387) · [Zoom Workplace Pro](https://www.zoom.com/en/products/collaboration-tools/zoom-workplace-pro/)

**Verification scope.** API and protocol tests cover admission, room cleanup, caption delegation, breakout choices, cloud record consent and file authorization. Four browser clients use bundled LiveKit for the collaborative workflows. The Windows speech test processes a real English audio fixture through the offline recognizer. The LiveKit recording template is exercised against real media sessions. Egress jobs and storage requests use fixtures. See [the test plan](test-plan.md) for commands and scope.

**Release status.** Calendar handoff uses iCalendar invites and a read-only hosted calendar feed. Hosted workspaces can also link and update selected Google Calendar events on request. Automatic invite email and background account synchronization remain open. Workplace-wide coverage, production capacity, and operating controls need additional implementation and verification.

The comparison also covers caption language, desktop appearance and statistics, and presentation annotation tools.
